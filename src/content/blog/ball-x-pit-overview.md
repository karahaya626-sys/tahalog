『BALL x PIT』は、**ブロック崩し・ボールの融合・拠点建築**を組み合わせたサバイバルローグライトである。

跳ね返るボールで大量の敵を倒す分かりやすい戦闘に、ローグライトらしいビルド構築と恒久的な拠点育成を組み合わせた作品だ。Steamでは英語レビュー14,000件以上のうち95％が好評となる「圧倒的に好評」を獲得している。

さらに2026年8月6日には、最後の無料コンテンツアップデート「The Naturalist Update」が配信されたばかり。Steamでは現在セールも実施されている。

筆者も現在プレイ中だが、今回はまず公式情報とコミュニティ評価を中心に、どんなゲームなのかを整理する。実際に遊んで感じた部分は、別記事でプレイレポとしてまとめる予定である。

> ※本記事は2026年8月8日時点の情報をもとにしている。セール価格やレビュー件数は今後変動する可能性がある。

## 『BALL x PIT』とは

『BALL x PIT』は、Kenny Sun and Friendsが開発し、Devolver Digitalから2025年10月15日に発売されたローグライトゲームである。

Steam公式では「ブロック崩し、ボール融合、基地建設を組み合わせたサバイバルローグライト」と紹介されている。

| 項目 | 内容 |
|---|---|
| 開発 | Kenny Sun and Friends |
| 販売 | Devolver Digital |
| 発売日 | 2025年10月15日 |
| ジャンル | ブロック崩し・ローグライト・拠点建築 |
| Steam対応OS | Windows / macOS |
| 日本語 | インターフェイス・字幕に対応 |

基本となる戦闘では、画面下からボールを発射し、壁や敵に反射させながら迫ってくる敵を倒していく。

見た目はブロック崩しに近いが、中身はかなりローグライト寄り。ラン中にさまざまなボールやパッシブを獲得し、組み合わせながらビルドを作っていく。

## 60種類以上のボールを組み合わせる「融合」

『BALL x PIT』を特徴づけているシステムのひとつが、**ボールの融合（Fusion）**である。

公式によると、ゲームには60種類以上のランダムなボールが登場。ボール同士を融合させることで新たな効果を持つボールへ変化し、組み合わせには数百通りの結果が用意されている。

単純に強いボールを拾っていくだけではなく、どのボールを組み合わせるかまで含めてビルドを考えるのが本作の大きな特徴だ。

ローグライトで強力なシナジーを探したり、毎回違うビルドを組み立てたりするのが好きなら、かなり相性がよさそうである。

## 拠点「New Ballbylon」を再建する

戦闘と並んで大きな要素となっているのが、拠点「New Ballbylon」の建築である。

探索で集めた資源を使って拠点を発展させることができ、公式では70種類以上の建物が用意されている。建物からゲーム中のボーナスを得られるほか、新しいパワーアップやキャラクターの解放にもつながる。

さらに拠点に残ったキャラクターへ仕事を割り当て、資源集めを自動化することも可能だ。

**探索して資源を集める → 拠点を発展させる → 新しい要素を解放する → 再び探索する**という流れが、ゲーム全体の成長サイクルとして組み込まれている。

## 2026年8月6日に「The Naturalist Update」が配信

2026年8月6日には、無料コンテンツアップデート「The Naturalist Update」が配信された。

開発者のKenny Sun氏は、今回を予定されていた**最後の無料コンテンツアップデート**と案内している。

主な追加内容は以下の通り。

- 新キャラクター2体
- 新ボール11種類
- 新パッシブ5種類

追加キャラクターの「The Ballbearer」は、パッシブを使用できない代わりにボールスロットが2倍。「The Hoary Hoarder」は逆にボールスロットが2枠になる代わり、パッシブスロットが2倍になる。

新ボールには、敵を貫通する「Drill」や隕石を降らせる「Armageddon」なども追加された。

## Steamでは34％OFFセール中

2026年8月8日確認時点で、Steamでは『BALL x PIT』が**34％OFF**になっている。

Steamストア上のセール終了日は**8月20日**。大型アップデートが配信された直後でもあり、以前から気になっていたなら始めやすいタイミングである。

セール内容は変更される可能性があるため、購入前にはSteamストアで最新情報を確認してほしい。

## Steam評価は「圧倒的に好評」

コミュニティ評価もかなり高い。

2026年8月8日時点のSteam英語レビューでは、**14,916件中95％が好評**で「圧倒的に好評」。直近30日でも91％が好評となっている。

日本語レビューも「非常に好評」となっており、海外だけで評価されている作品というわけではない。

発売から時間が経った現在まで高い評価を維持しているのは、これから遊ぶ側にとっても安心材料になりそうだ。

## 海外コミュニティの評価

Redditなど海外コミュニティでも、特に**ボールの組み合わせや融合によるビルドの幅**を評価する声が目立つ。

毎回異なるボールを組み合わせて強力なシナジーを作る部分や、反射角度を考えながら大量の敵を一気に倒す爽快感を気に入っているプレイヤーが多い。

一方で、拠点建築については評価が分かれている。ランの合間に恒久的な成長を進められる点を評価する声がある一方、「後半は作業感が出る」「戦闘だけを続けたいときには少しテンポを止める」と感じるプレイヤーもいる。

また、長時間遊んだプレイヤーからは後半の周回や資源集めに繰り返しを感じるという意見も見られる。

Steam全体の評価は非常に高いものの、**戦闘とビルド構築は特に好評、拠点や終盤の周回は好みが分かれやすい**というのが、海外コミュニティを見た印象である。

## こんな人に合いそう

『BALL x PIT』は、以下のような人なら特にチェックしてみてよさそうだ。

- ローグライトが好き
- ビルドやシナジーを考えるのが好き
- 強力な組み合わせを探すのが好き
- ブロック崩しのような反射を利用した戦闘が気になる
- ランを繰り返しながら恒久的に成長していくゲームが好き
- 拠点を少しずつ発展させるゲームが好き

ブロック崩しをそのままローグライトにしただけではなく、**「ボール融合」と「拠点建築」をゲームの中心に組み込んでいる**のが『BALL x PIT』ならではの部分である。

Steamでは「圧倒的に好評」を獲得しており、2026年8月6日には最後の無料コンテンツアップデート「The Naturalist Update」も配信されたばかり。
